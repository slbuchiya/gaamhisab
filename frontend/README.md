# ગામ હિસાબ – React Frontend (Vite)

## ચલાવો
    npm install
    npm run dev          # http://localhost:5173

`VITE_API_URL` ખાલી હોય તો ડેમો મોડ (લૉગિન: pramukh / 1234, ડેટા બ્રાઉઝરમાં).
સાચા બેકએન્ડ માટે `.env` ફાઇલ બનાવો:  `VITE_API_URL=https://tamaru-render-link.onrender.com`

## Vercel
Root Directory = frontend, Framework = Vite (auto), Environment Variable: VITE_API_URL = Render નું લિંક.
